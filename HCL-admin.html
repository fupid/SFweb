Update Database from New CSV Export
Use this when you have fresh CSV exports from Sangfor compatibility portal
1
Download fresh CSV from Sangfor portal
Name the files starting with sangfor_site1_ or sangfor_site2_ and ending with .csv. Example: sangfor_site1_complete_2026-06-01.csv
2
Place the CSV file in the same folder as this website
Same directory as HCL-index.html
3
Run the converter script
Open a terminal in the website folder and run:
node HCL-convert_csv_to_json.js
This regenerates HCL-compatibility_data.json and HCL-compatibility_data.js, preserving any manually-added entries.
4
Refresh the browser
The website will automatically load the updated database on next page refresh.
